## Подробное описание
Проект на Next.js (App Router) реализует интерфейс для создания заданий генерации видео, просмотра результатов и управления публикацией. Канал публикации в текущей версии: только VK Clips.

## Текущий статус
- Реализован UI, API-роуты и pipeline генерации/рендера
- Интеграция VK Clips включена как единственный канал публикации

## Запуск локально
### Вариант 1: Docker Compose (рекомендуется)

1) Скопируйте переменные окружения:

```bash
cp .env.example .env.local
```

2) Заполните обязательные ключи в `.env.local` (Supabase, Clerk, VK, AI API keys).

3) Запустите приложение и Inngest:

```bash
docker compose up --build
```

4) Откройте:
- App: http://localhost:3000
- Inngest: http://localhost:8288

### Вариант 2: Локально без Docker

1) Установите зависимости и запустите dev-сервисы:

```bash
npm install
npm run dev
npx inngest-cli@latest dev  # Запуск Inngest (очереди задач для AI-агента)
```

2) Откройте приложение: http://localhost:3000

Примечания:
- Если вы используете `pnpm` или `yarn`, замените команды соответственно.
- Для OAuth callback VK нужен корректный `NEXT_PUBLIC_APP_URL` (например `http://localhost:3000`).

## Архитектура (высокоуровневая)
Пользователь → Frontend (Next.js UI) → Inngest pipeline → Генератор видео → VK API (VK Clips)

Frontend и API-роуты отвечают за создание задания, визуализацию статуса и запуск пайплайна генерации/публикации.

---

## Пример рабочего процесса (MVP)
1. Пользователь создаёт задание в UI (текстовый промпт, настройки).
2. Frontend отправляет задание в API.
3. Агент генерирует видео и сохраняет результат в storage.
4. Workflow публикует видео в VK Clips.
